# Changelog

## v1.0.0

- First version: the launcher icons of the Ez addons (EzEmote, EzOutfitter, EzAcquaintances, EzLines, EzNotebook) gather in one dock above the chat box, the same on every character.
- Click the small handle to fold the icons away and back (works in combat too). While folded, a gold mark on the handle tells you an icon is waiting for you.
- Unlocked, drag the handle to move the dock and an icon to change the order. An icon its addon hides leaves no gap, and takes its place again when it shows.
- Options (`/dock`): which way the icons line up, icons per row, size, spacing, fade when the mouse is elsewhere, background, and an Icons page to pick and order them.
